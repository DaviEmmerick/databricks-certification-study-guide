# Simulado 1 — Databricks Generative AI Engineer Associate

> [!important]
> **Atualizado para o blueprint de março de 2026.** A terminologia foi atualizada para os nomes atuais dos produtos (Unity AI Gateway, Mosaic AI Vector Search, Lakeflow Jobs). A distribuição por domínio reflete a estrutura atual de 6 domínios, incluindo Governance (8 %).
>
> Os títulos das seções em `questions.md` mantêm os quatro agrupamentos temáticos originais para preservar a estabilidade dos IDs das questões; o debrief associa cada questão à seção correspondente do guia do exame. Os itens acrescentados ao guia de 18 de março de 2026 (Agent Bricks, MCP, juízes e scorers, monitoramento do AI Gateway) são abordados nos [conjuntos de prática 05–07](../practice-questions/README.md).

## Instruções do exame

| Detalhe | Valor |
| ------ | ----- |
| Total de questões | 45 |
| Tempo limite | 90 minutos |
| Resultado | Aprovado / reprovado (o guia do exame não informa uma nota numérica de corte) |
| Formato | Múltipla escolha, uma resposta correta (o exame real também inclui questões de seleção múltipla) |

## Guia de pontuação

| Pontuação | Resultado |
| ----- | ------ |
| 36–45 (≥ 80 %) | Excelente |
| 32–35 (70–79 %) | Provavelmente aprovado |
| 27–31 (60–69 %) | Quase lá — é necessário estudar com foco |
| Menos de 27 (< 60 %) | É necessária uma revisão abrangente |

> [!note]
> A Databricks não publica uma nota numérica de aprovação para o guia atual do exame.
